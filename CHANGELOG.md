# Changelog

## 0.1.0 - 2026-10-29

The first public release of PR Notes for BB.

- Find assigned PRs and review requests across repositories, with search, filters, infinite scrolling, and cached views.
- Read descriptions with code chips and file links, follow activity, and post Markdown comments from Overview.
- Inspect unified or side-by-side diffs and grouped GitHub checks with workflow names, durations, annotations, and run links.
- Keep private notes with preview, draft recovery, and conflict handling.
- Start a native BB chat with PR context and saved notes; keep the composer at the bottom and reopen conversations later.
- Merge, mark draft/ready, and close/reopen PRs with confirmation, GitHub access checks, and revision guards.
- Read current PR context through the `pr_notes_context` tool and `bb pr-notes` commands.
